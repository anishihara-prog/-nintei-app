# 手動テスト用ケース10件（今回のセッションでの変更点を確認する用）

実データは使わないこと。すべて架空の設定。

このセッションで以下の変更を行った。10件のケースはそれぞれ、その変更点を実際にアプリを
操作して手動で確認するために作った。

1. 項目の並び順を、実際の調査票シートの出現順（区分をまたぐ）に変更
2. 項目一覧に、細区分の見出し（起居動作／生活機能１等、10個）を追加表示
3. 「まとめる」機能で、区分（群）をまたいだ項目選択を禁止
4. 特記事項.xlsxの記入欄が不足する場合、その場で行を動的に追加するよう変更（以前は超過分が無警告で消えていた）

各ケースは「① アプリで選択・入力する項目」「② 確認すること」の2部構成。
①を実際にアプリ左側で選択・特記文を入力し、②を見て期待通りか確認する。
